# Health & Nutrition Tracking Application

**Technologies:** Python | SQLite | Tkinter | Matplotlib

## Project Overview

Developed a Python desktop application designed to help users monitor their health, nutrition, and fitness activities through an integrated tracking system.

The application combines data management, algorithmic optimisation, and interactive visualisations to provide users with a structured way to track their progress.

## Key Features

- **Nutrition Tracking:** Record and manage nutritional information.
- **Workout Tracking:** Log fitness activities and monitor progress.
- **Database Management:** Designed and implemented a relational SQLite database following database normalisation principles (1NF–3NF).
- **Search Optimisation:** Implemented a binary search algorithm, reducing worst-case comparisons from approximately 100,000 to 17 for a sorted dataset of 100,000 records.
- **Account Security:** Implemented password hashing to improve user account security.
- **Data Visualisation:** Integrated Matplotlib to display health and fitness data graphically.
- **Graphical User Interface:** Built a desktop interface using Tkinter.

## Software Development & Testing

Followed an iterative software development lifecycle, incorporating:

- Stakeholder interviews to identify user requirements.
- Usability evaluations to improve the user experience.
- Over 30 tests assessed against 45 defined success criteria.
- Modular software design to improve maintainability.
